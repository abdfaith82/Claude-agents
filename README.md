# ClaudeRelay

تطبيق أندرويد (Kotlin + Jetpack Compose) يوزّع المهام على عدة وكلاء ذكاء اصطناعي، ويكمل التالي إذا توقف أحدهم.

## النسخة الاحتياطية المحلية للوكلاء (v1.1)

الوكلاء بمفاتيحهم تُحفظ في مجلد تختاره على جهازك لتعود عند تحديث التطبيق أو إعادة تثبيته.

- **حفظ تلقائي:** بعد كل إضافة أو حذف أو تعديل للوكلاء يُكتب الملف `claude-relay-agents.json` في المجلد.
- **استعادة تلقائية:** عند فتح التطبيق، إن كانت قائمة الوكلاء فارغة والمجلد متاح، تُستعاد الوكلاء.
- **تشفير اختياري:** بكلمة مرور (AES-256-GCM، والمفتاح مشتق بـ PBKDF2-SHA256). بدونها تُحفظ المفاتيح كنص عادي في الملف.
- **استعادة من ملف** و**تصدير يدوي** من تبويب «الوكلاء».
- لا يُكتب فوق ملف نسخة لا يستطيع التطبيق قراءته (مشفّر بكلمة أخرى أو تالف)، وتُدمج الوكلاء المستعادة دون تكرار.

> **ملاحظة مهمة:** إلغاء تثبيت التطبيق يلغي إذن المجلد، لذلك بعد إعادة التثبيت اختر «استعادة من ملف» ثم اختر المجلد من جديد.
> ولو كانت كل نسخة APK تُبنى على Actions بتوقيع debug مختلف فلن يُثبَّت التحديث فوق القديم، فيلزم إلغاء التثبيت أولاً. استخدم مفتاح توقيع ثابتاً لتتفادى ذلك.

## البناء

Gradle 8.5 + AGP 8.2.2 + Kotlin 1.9.22 + JDK 17. يبني `gradle assembleDebug` عبر GitHub Actions ويرفع `app-debug.apk` كـ artifact.
